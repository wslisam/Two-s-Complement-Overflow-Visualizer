# Two's Complement & Overflow Visualizer

Welcome to the Two's Complement interactive tool! This simple, self-contained web app is designed to help student visualize and understand how computers store positive and negative numbers.

## How to Use This Tool for Self-Study

1. **Read the Learning Goals:** Start at the top to understand what you should be focusing on.
2. **Play with the Simulator:** - Type different numbers (between -128 and 127) into the input box.
   - Watch how the binary bits change. 
   - Look at the weights below the bits! Try adding up the weights where the bit is `1` to see how it perfectly equals your decimal number.
   - Use the `+ 1` and `- 1` buttons to intentionally trigger an **Overflow** (try going past 127 or below -128) and observe what happens to the red Sign Bit.
3. **Review the Formulas:** Once you've played with the tool, scroll down to see the math behind it. The formulas will make much more sense after you've visually seen the weights in action!
4. **Check the Misconceptions:** Make sure you haven't fallen into the common traps that confuse many beginners.
5. **Think & Link:** Test your understanding by answering the final critical thinking question. This is great preparation for exams or class discussions!
